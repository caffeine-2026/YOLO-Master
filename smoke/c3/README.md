# C3｜工业缺陷检测 V-PEFT 小样本实战

> 首轮全量测试 / 首个可比实验数据进展（数据截止：2026-08-31）

## 一、课题目标

本课题在 **NEU-DET** 与 **DeepPCB** 两个工业缺陷数据集上，对比三种训练策略：

- **Full-SFT**：全参数微调；
- **Frozen Backbone**：冻结骨干网络，仅训练其余可训练部分；
- **V-PEFT**：由 planner 选择注入目标并进行参数高效微调。

核心问题不是预设 V-PEFT 必须取得最高精度，而是验证它在不同小样本规模下能否以更少的可训练参数保留合理精度，并如实记录精度、显存与训练时间之间的权衡。

## 二、本轮完成情况

### P0：最小闭环与真实性检查

- NEU-DET、DeepPCB 均完成一次 RTX 4090 / GPU 0 / FP32 / 1 epoch 的 V-PEFT 最小闭环；
- planner 均为严格模式，决策为 `ACCEPT`，实际后端为 `peft`；
- 两次运行均有非空 adapter 导出，未发生 fallback 或数值恢复，退出码均为 0；
- P0 仅证明链路可以真实运行，**不用于证明方法优越性**。

详见 [P0 说明与验收证据](p0/README.md)。

### P1：100-shot 可比实验

- 在固定数据划分、模型、优化器、增强策略与训练预算下，对三种方法进行 100-shot 对照；
- P1 产出的 18 个 `数据集 × 方法 × seed` 单元已作为不可变结果复用于 P2；
- 资源指标与参数效率已单独记录，避免只看精度得出片面结论。

详见 [P1 对照实验](p1/README.md) 与 [V-PEFT 多 seed 效率分析](p1/docs/VPEFT_EFFICIENCY_ANALYSIS.md)。

### P2：首轮多 seed 小样本缩放矩阵

- 数据集：NEU-DET、DeepPCB；
- 样本规模：10 / 50 / 100 / 500；
- 方法：Full-SFT / Frozen Backbone / V-PEFT；
- 随机种子：824 / 825 / 826；
- 共 `2 × 4 × 3 × 3 = 72` 个实验单元，最终验证 **72/72 PASS**；
- 所有 V-PEFT 单元均通过严格后端与 adapter 完整性检查（24/24 PASS）。

训练协议固定为 YOLO11n、100 epochs、batch 8、imgsz 640、AdamW、`lr0=0.001`、`weight_decay=0.0005`、cosine scheduler；两个数据集均采用 `10 ⊂ 50 ⊂ 100 ⊂ 500` 的嵌套训练子集，并固定验证集与测试集。

最终门禁见 [P2 final validation](p2/evidence/p2_final_validation.json)。

## 三、首个可比实验结果

下表为三次独立 seed 的 **mAP50-95 均值**；Retention 为 `V-PEFT / Full-SFT`。

| 数据集 | 训练图像数 | Full-SFT | Frozen Backbone | V-PEFT | V-PEFT Retention |
| --- | ---: | ---: | ---: | ---: | ---: |
| NEU-DET | 10 | 0.1212 | **0.1325** | 0.1192 | 98.33% |
| NEU-DET | 50 | **0.2687** | 0.2195 | 0.2505 | 93.26% |
| NEU-DET | 100 | **0.3329** | 0.2935 | 0.3203 | 96.20% |
| NEU-DET | 500 | **0.3995** | 0.3769 | 0.3909 | 97.83% |
| DeepPCB | 10 | **0.2903** | 0.2206 | 0.1897 | 65.34% |
| DeepPCB | 50 | **0.5669** | 0.3898 | 0.3709 | 65.42% |
| DeepPCB | 100 | **0.6486** | 0.4844 | 0.5166 | 79.65% |
| DeepPCB | 500 | **0.7006** | 0.5979 | 0.6564 | 93.69% |

完整均值、标准差与 95% 置信区间见 [P2 summary](p2/results/p2_summary.md)，同 seed 配对差值见 [paired analysis](p2/results/paired_analysis.md)。当前只有 3 个 seed，因此不作 p-value 或普适显著性结论。

## 四、初步分析

### 1. V-PEFT 的稳定优势是可训练参数更少

- Full-SFT：2,590,994 个可训练参数；
- Frozen Backbone：1,225,522 个可训练参数；
- V-PEFT：613,602 个可训练参数；
- V-PEFT 相比 Full-SFT 固定减少 **76.32%**，相比 Frozen Backbone 约减少 **49.93%**。

这是当前矩阵中最稳定、最直接的 V-PEFT 优势。

### 2. 精度收益取决于数据集与样本规模

- V-PEFT 的 mAP50-95 均值在 8 个 `数据集 × 样本规模` 条件中的 **5 个高于 Frozen Backbone**，但并非所有条件都更好；
- NEU-DET 上 V-PEFT 保留了 Full-SFT 的 93.26%–98.33%，差距较小；
- DeepPCB 上 10/50-shot 的 retention 仅为 65.34%/65.42%，到 500-shot 才提升到 93.69%；
- V-PEFT 在本轮 8 个均值单元中均未超过 Full-SFT，因此现有证据不支持“V-PEFT 精度普遍优于全参数微调”的表述。

### 3. 参数减少没有自动转化为显存或速度优势

- 相比 Full-SFT，V-PEFT 的峰值显存节省仅约 **1.14%–1.53%**；
- 实测 GPU-hours 反而增加约 **5.67%–19.57%**；
- 当前实现中，激活、优化器/框架开销以及 adapter/planner 路径可能占据主要成本，但这只是待 profiler 验证的机制假设，不能由现有结果直接确认为因果关系。

因此目前应将 V-PEFT 定位为“显著减少可训练参数，并在部分数据区间保持较高精度”的方案，而不是“已证明更快、更省显存或精度最高”的方案。

## 五、当前困难与风险

1. **DeepPCB 极小样本差距明显**：10/50-shot 下 V-PEFT 与 Full-SFT 的差距稳定存在，需要优先分析目标层、rank 与学习率是否适合高密度小目标。
2. **低样本方差较大**：NEU-DET 10-shot 的方法排序在不同 seed 间方向不一致，不能只使用单个 seed 下结论。
3. **参数效率不等于运行效率**：可训练参数数目不能直接代表峰值显存或 wall-clock 时间。
4. **机制解释仍是描述性证据**：NEU-DET 与 DeepPCB 的目标密度、框面积和图像分布不同，但现阶段不能把这些相关性写成已证实的因果机制。

## 六、下一步计划

1. 保持当前 72-cell 矩阵为只读基线，不修改或筛选已有测试结果；
2. 先针对 DeepPCB 10/50-shot 做失败样本与目标尺度分析；
3. 在固定训练预算和固定测试集的前提下，只使用验证集选择配置，进行小规模单变量消融：
   - adapter rank；
   - planner 目标层；
   - V-PEFT 学习率；
4. 只有当改动在多个 seed 上稳定改善后，才提交新的对照矩阵，并同时报告精度、参数量、显存与 GPU-hours；
5. 使用 profiler 验证显存和耗时开销来源，避免仅依据参数量推断速度。

## 八、希望社区讨论的问题

1. 在“可训练参数减少 76.32%，但显存与训练时间没有同步改善”的情况下，后续更应优先优化运行实现，还是先改善 DeepPCB 低样本精度？
2. 对高密度小目标数据，V-PEFT 的目标层选择与 rank 是否应随样本规模变化，还是应保持统一配置以保证公平比较？

当前结论：**首轮实验链路与首个可比矩阵已完成，P2 总体验收为 PASS；V-PEFT 展现出明确的参数效率，但其精度与运行效率优势具有数据集和样本规模依赖性，仍需受控消融验证。**
